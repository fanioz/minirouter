# Story 4.1: Built-in Playground Chatbox

## Status
Ready for Review

## Story
**As a** User or Developer testing the API,
**I want** a built-in playground chatbox interface inside the dashboard,
**so that** I can rapidly test prompts, model responses, and system latency without needing an external third-party chat client.

## Acceptance Criteria
1. The frontend Dashboard UI includes a new "Playground" tab or route.
2. The Playground provides a basic chat interface (input box for messages, output area for the conversation).
3. The Playground allows selecting the target `model` via a dropdown (dynamically populated from available providers).
4. The Playground sends standard `POST /v1/chat/completions` requests to the MiniRouter backend using the selected model.
5. The chat interface supports rendering streaming responses correctly (since the API streams back responses by default).
6. The chat interface is styled consistently with the existing Svelte frontend dashboard.

- **Data Models**: The chat must format messages as `{"role": "user", "content": "..."}` matching the OpenAI spec.
- **API Specifications**: Target `/v1/chat/completions`.
- **Component Specifications**: Use Svelte 5 state management (`$state`) for the message history list.
- **Technical Constraints**: No backend changes are strictly necessary unless we need a new endpoint to fetch all active models.
