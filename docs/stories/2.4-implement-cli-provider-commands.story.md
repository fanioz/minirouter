# Story 2.4: Implement CLI Provider Commands

## Status
Done

## Story
**As a** Developer,
**I want** to add `providers add`, `providers edit`, and `providers delete` commands to the Spectre.Console CLI,
**so that** users can fully manage the MiniRouter providers from the command line.

## Acceptance Criteria
1. A `minirouter providers add` command is implemented, prompting the user for necessary provider details and saving them.
2. A `minirouter providers edit` command is implemented, allowing the user to select and update an existing provider.
3. A `minirouter providers delete` command is implemented to remove a provider.
4. Input validation and error handling (e.g., checking for duplicate names, invalid URLs) are properly enforced with informative CLI feedback.
