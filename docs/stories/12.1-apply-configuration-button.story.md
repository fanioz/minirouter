# Story 12.1: Apply Configuration Button for CLI Tools

## Status

Draft

## Story

As a MiniRouter operator,
I want to click an "Apply Configuration" button in the Integrations tab,
So that the MiniRouter provider configuration is automatically written to my CLI tool's config file (Claude Code or Codex CLI) without manual copy-paste or file system navigation.

## Acceptance Criteria

1. `POST /api/config/apply-claude-code` endpoint exists and is protected by `ApiKeyEndpointFilter`.
2. `POST /api/config/apply-codex` endpoint exists and is protected by `ApiKeyEndpointFilter`.
3. Clicking "Apply Configuration" for Claude Code writes to `~/.claude/config.json` (Unix) or `%USERPROFILE%\.claude\config.json` (Windows).
4. Clicking "Apply Configuration" for Codex CLI writes to `~/.codex/config.toml` (Unix) or `%USERPROFILE%\.codex\config.toml` (Windows).
5. Existing providers and keys in the config file are preserved (idempotent merge — only the `minirouter` provider entry is added/updated).
6. If the config file doesn't exist, it is created with the `minirouter` provider as the only entry.
7. If the config file is malformed (invalid JSON/TOML), the endpoint returns `500` with a clear error message in the response body.
8. If the server process doesn't have write permission to the target file, the endpoint returns `403` with a clear error message.
9. If the target path resolves outside `$HOME` (Unix) or `%USERPROFILE%` (Windows), the endpoint returns `403` with error message "Path is outside user home directory".
10. Unauthenticated requests return `401` (handled by `ApiKeyEndpointFilter`).
11. Success response (`200 OK`) includes JSON: `{ "path": "<absolute-path-to-written-file>" }`.
12. Frontend shows success toast on `200`: "✓ Configuration applied to {path}. Restart {tool-name} to activate."
13. Frontend shows error toast on `403`/`500`: "⚠ {detail-from-response-body}".
14. Browser `confirm()` modal prompts user before writing: "This will write to {path}. Continue?"
15. Button is disabled during the API call (prevent double-clicks).
16. All new and existing tests pass; `dotnet build` clean; `npm run build` clean.

## Tasks / Subtasks

### Task 1 — `ConfigApplyService.cs` — Core Service (AC: 3, 4, 5, 6, 7, 8, 9)

**File:** `Services/ConfigApplyService.cs` (new)

Build a service that handles idempotent config file writes with path validation and merge logic.

- [ ] 1.1 Create `public class ConfigApplyService` with DI constructor (inject `IConfiguration` to read MiniRouter's `BASE_URL` and default model).
- [ ] 1.2 Add method `public async Task<ConfigApplyResult> ApplyClaudeCodeConfigAsync(CancellationToken ct = default)`:
  - Resolve path: `$HOME/.claude/config.json` (Unix) or `%USERPROFILE%\.claude\config.json` (Windows).
  - Call `ValidatePathInHomeDirectory(path)` — return `ConfigApplyResult.Fail("Path is outside user home directory")` if false.
  - Call `ValidateWritePermissionAsync(path)` — return `ConfigApplyResult.Fail("No write permission: {path}")` if false.
  - Read existing config (if file exists) via `File.ReadAllTextAsync`, parse as `JsonNode`.
  - If parse fails (invalid JSON), return `ConfigApplyResult.Fail("Existing config is invalid JSON")`.
  - Build `minirouter` provider entry:
    ```json
    {
      "name": "MiniRouter",
      "base_url": "http://localhost:8080/v1",
      "default_model": "providerId/modelName"
    }
    ```
  - Merge: insert/update `customProviders["minirouter"] = <entry>` (preserve other keys).
  - Write back: ensure parent directory exists (`Directory.CreateDirectory(Path.GetDirectoryName(path))`), write JSON with `JsonSerializerOptions { WriteIndented = true }`.
  - Return `ConfigApplyResult.Success(path)`.

- [ ] 1.3 Add method `public async Task<ConfigApplyResult> ApplyCodexConfigAsync(CancellationToken ct = default)`:
  - Resolve path: `$HOME/.codex/config.toml` (Unix) or `%USERPROFILE%\.codex\config.toml` (Windows).
  - Call `ValidatePathInHomeDirectory(path)` — return failure if false.
  - Call `ValidateWritePermissionAsync(path)` — return failure if false.
  - Read existing config (if file exists), parse as TOML via `Tomlyn.Toml.ToModel<TomlTable>(text)`.
  - If parse fails, return `ConfigApplyResult.Fail("Existing config is invalid TOML")`.
  - Build `[model_providers.minirouter]` table:
    ```toml
    name     = "MiniRouter"
    base_url = "http://localhost:8080/v1"
    env_key  = "MINIROUTER_API_KEY"
    wire_api = "responses"
    ```
  - Merge: ensure `model_providers` table exists, insert/update `model_providers["minirouter"] = <entry>` (preserve other keys).
  - Write back: serialize via `Tomlyn.Toml.FromModel(table)`, write to file.
  - Return `ConfigApplyResult.Success(path)`.

- [ ] 1.4 Add helper `private string ResolveConfigPath(string toolName)`:
  - Returns canonical absolute path: `Path.GetFullPath(Path.Combine(homeDir, $".{toolName}/config.{ext}"))`.
  - Detect `homeDir`: `Environment.GetFolderPath(Environment.SpecialFolder.UserProfile)` (works on both Unix and Windows).

- [ ] 1.5 Add helper `private bool ValidatePathInHomeDirectory(string path)`:
  - Canonicalize: `Path.GetFullPath(path)`.
  - Check prefix: `path.StartsWith(homeDir)` (case-insensitive on Windows).
  - Prevent traversal: reject if `path.Contains("..")` after canonicalization.
  - Return `true` if valid, `false` otherwise.

- [ ] 1.6 Add helper `private async Task<bool> ValidateWritePermissionAsync(string path)`:
  - If file exists: check write permission via `File.GetAttributes` + `FileAttributes.ReadOnly`.
  - If file doesn't exist: check parent directory write permission via `Directory.GetAccessControl` + `FileSystemRights.Write` (or try-create-temp-file pattern).
  - Return `true` if writable, `false` otherwise.

- [ ] 1.7 Create result record:
  ```csharp
  public record ConfigApplyResult(bool Success, string? ErrorMessage, string? ConfigPath)
  {
      public static ConfigApplyResult Success(string path) => new(true, null, path);
      public static ConfigApplyResult Fail(string error) => new(false, error, null);
  }
  ```

- [ ] 1.8 Register service in DI: add `builder.Services.AddScoped<ConfigApplyService>();` to `Program.cs` services section.

  ```typescript
  async function handleApplyConfig() {
    const targetPath = isWindows ? '%USERPROFILE%\\.claude\\config.json' : '~/.claude/config.json';
    const confirmed = confirm(`This will write MiniRouter configuration to ${targetPath}. Continue?`);
    if (!confirmed) return;

    isApplying = true;
    try {
      const response = await fetch('/api/config/apply-claude-code', {
        method: 'POST',
        headers: { 'X-Api-Key': $apiKeyStore } // import from store

        showToast(`⚠ ${detail || 'Failed to apply configuration'}`, 'error');
      }
    } catch (err) {
      showToast(`⚠ Network error: ${err.message}`, 'error');
    } finally {
      isApplying = false;
    }
  }
  ```

  ```typescript
  import { writable } from 'svelte/store';

  function createToastStore() {
    const { subscribe, update } = writable([]);

    return {
      subscribe,
      show: (message, type = 'info', duration = 5000) => {
        const id = Date.now();
        update(toasts => [...toasts, { id, message, type }]);
        setTimeout(() => {
          update(toasts => toasts.filter(t => t.id !== id));
        }, duration);
      }
    };
  ```

## Dev Notes

### Idempotent Merge Strategy

**Claude Code (`config.json`):**
```csharp
var existing = JsonSerializer.Deserialize<JsonObject>(text) ?? new JsonObject();
var customProviders = existing["customProviders"]?.AsObject() ?? new JsonObject();
customProviders["minirouter"] = new JsonObject { /* ... */ };
existing["customProviders"] = customProviders;
await File.WriteAllTextAsync(path, JsonSerializer.Serialize(existing, options));
```

**Codex CLI (`config.toml`):**
```csharp
var table = Toml.ToModel(text) ?? new TomlTable();
var modelProviders = table.ContainsKey("model_providers") 
    ? (TomlTable)table["model_providers"] 
    : new TomlTable();
modelProviders["minirouter"] = new TomlTable { /* name, base_url, env_key, wire_api */ };
table["model_providers"] = modelProviders;
await File.WriteAllTextAsync(path, Toml.FromModel(table));
```

### Platform Path Detection

Both Unix and Windows:
```csharp
string homeDir = Environment.GetFolderPath(Environment.SpecialFolder.UserProfile);
// Unix: /home/username
// Windows: C:\Users\username
```

### Security: Path Canonicalization

Use `Path.GetFullPath(path)` to resolve `..`, symlinks, and relative paths before checking prefix. Example:
```csharp
string canonical = Path.GetFullPath(path);
string homeDir = Environment.GetFolderPath(Environment.SpecialFolder.UserProfile);
if (!canonical.StartsWith(homeDir, StringComparison.OrdinalIgnoreCase)) {
    return ConfigApplyResult.Fail("Path is outside user home directory");
}
```

### Write Permission Check

If file exists:
```csharp
var attrs = File.GetAttributes(path);
if ((attrs & FileAttributes.ReadOnly) != 0) return false;
```

If file doesn't exist (check parent directory):
```csharp
var parentDir = Path.GetDirectoryName(path);
// Try creating a temp file in the same directory:
try {
    var tempFile = Path.Combine(parentDir, Path.GetRandomFileName());
    File.WriteAllText(tempFile, "");
    File.Delete(tempFile);
    return true;
} catch {
    return false;
}
```
