# Story 8.1: Restore Test Project Compilation

## Description

`Tests/MiniRouter.Tests.csproj` does not compile. Until it does, **no story in this epic is
verifiable** — there is no way to confirm a routing or circuit-breaker change has not broken
existing behavior.

Two separate problems:

**1. Constructor drift (6 × CS7036).** `ApiKeyService` gained an `IMemoryCache` parameter
(`Services/ApiKeyService.cs:15`), but `Tests/ApiKeyServiceTests.cs` still calls
`new ApiKeyService(_config)` at lines 40, 56, 69, 85, 98, and 112.

**2. Stale assertions in `ProxyServiceTests.cs`.** Two of three tests assert auth behavior
that has since moved out of `ProxyService` into `Filters/ApiKeyEndpointFilter.cs`.
`HandleChatCompletionAsync` no longer contains a 401 path and never emits the string
"Missing or invalid Authorization header". These tests will *fail* once compilation is
restored — fixing the build alone is not enough.

Related: `_apiKeyServiceMock` is still injected into `ProxyService` in the test setup, but the
service no longer calls it. Stale dependency, safe to remove.
