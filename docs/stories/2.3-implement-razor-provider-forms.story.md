# Story 2.3: Implement Razor Pages Provider Forms

## Status
Done

## Story
**As a** Developer,
**I want** to add Create, Edit, and Delete functionalities to the Razor Pages dashboard,
**so that** users can fully manage the MiniRouter providers through the standard JIT UI.

## Acceptance Criteria
1. A `Create` Razor Page is implemented, allowing users to add a new provider to the configuration.
2. An `Edit` Razor Page is implemented, allowing users to modify an existing provider.
3. `Delete` functionality is implemented (either as a separate page or a secure POST action).
4. Data validation is enforced for all provider properties (e.g., required fields, URL formats).
5. Navigation links/buttons (Create New, Edit, Delete) are added to the existing Provider List view (`Index.cshtml`).
