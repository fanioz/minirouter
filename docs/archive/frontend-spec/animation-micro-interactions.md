# Animation & Micro-interactions

**Motion Principles:** Fast, purposeful, and unobtrusive. Animations should not slow down the user.
**Key Animations:**
- **Modal Fade/Scale:** Modals appear with a quick 150ms fade-in and slight scale-up.
- **Button Hover:** 100ms transition on background color.
- **Toast Notifications:** Slide in from the bottom right, disappear after 3 seconds.
