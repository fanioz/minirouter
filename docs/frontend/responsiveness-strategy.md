# Responsiveness Strategy

## Breakpoints
| Breakpoint | Min Width | Target Devices |
|------------|-----------|----------------|
| Mobile     | 320px     | Phones         |
| Tablet     | 768px     | iPads, Tablets |
| Desktop    | 1024px    | Laptops        |

## Adaptation Patterns
**Layout Changes:** The data table should switch to a card-based layout on Mobile to avoid horizontal scrolling, or allow a horizontally scrollable table container. Modals should become full-screen on mobile.
**Navigation Changes:** The header adapts padding but remains a single bar.
