# Branding & Style Guide

## Visual Identity
**Brand Guidelines:** The aesthetic should be "Developer-First Minimalist"—dark mode friendly, high contrast, clean lines, heavily relying on monochrome with one accent color.

## Color Palette
| Color Type | Hex Code | Usage |
|------------|----------|-------|
| Primary    | `#000000`| Backgrounds (Light mode), Text (Light) |
| Accent     | `#3b82f6`| Buttons, active states, links (Blue) |
| Success    | `#22c55e`| Positive feedback, confirmations |
| Error      | `#ef4444`| Destructive actions (Delete button), errors |
| Neutral    | `#f3f4f6`| Borders, card backgrounds (Light mode) |

## Typography
- **Primary:** Inter or Roboto (System fonts preferred for performance)
- **Monospace:** Fira Code or JetBrains Mono (For API keys, provider IDs)

## Spacing & Layout
**Grid System:** Standard 12-column grid, max-width container (e.g., max-w-5xl).
**Spacing Scale:** Tailwind default 4pt spacing scale (e.g., p-4, m-8).
