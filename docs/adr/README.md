# Architecture Decision Records

ADRs capture significant architecture decisions as short, numbered documents, created **lazily** as decisions are made — per the root [`AGENTS.md`](../../AGENTS.md) and [`docs/agents/domain.md`](../agents/domain.md).

## Conventions

- File name: `NNNN-short-decision.md` (e.g. `0001-explicit-provider-routing.md`), zero-padded, next number in sequence.
- Keep each record short: context, decision, consequences. Treat records as immutable — supersede with a new ADR rather than editing.
